# Keke的新西兰之旅 (New Zealand Journey Tracker)

这是一个极简的网页应用，用于追踪入境新西兰的天数、工作经验积累进度以及手动记录工作日志。

## ✨ 核心功能

1.  **入境倒计时/天数统计**: 自动计算从 2025-03-19 开始的天数。
2.  **RV 进度条**: 追踪 1.5 年工作经验的达成情况。
3.  **工作日志**: 手动记录每一段工作时间，支持多设备数据同步。

---

## 🚀 如何同步数据 (极简模式)

本项目没有后台数据库，而是通过维护代码仓库根目录下的 `work_logs.json` 文件来同步数据。

**同步流程：**

1.  **记录**: 在网页上添加新的工作记录。
2.  **下载**: 点击右上角的 **“下载 JSON”** 按钮。
3.  **覆盖**: 将下载的文件直接**替换**项目根目录下的 `work_logs.json` 文件。
4.  **推送**: 将代码提交并推送到 GitHub。
    ```bash
    git add work_logs.json
    git commit -m "Update logs"
    git push
    ```
5.  **完成**: 等待 Cloudflare Pages 自动部署（约1分钟）。之后在任何设备打开网页，都会自动加载最新的数据。

---

## 🛠️ 本地开发

1.  安装依赖: `npm install`
2.  启动服务: `npm run dev`
3.  构建项目: `npm run build`

## ⚠️ 注意事项

- 网页会优先合并 **本地浏览器缓存** 和 **服务器上的 work_logs.json**。
- 如果你在 GitHub 上直接手动删除了 json 文件里的某条记录，但浏览器本地缓存里还有，它可能还会显示。此时**清除浏览器缓存**即可强制同步服务器文件。
